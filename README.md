# Trace · PCB Inspection Studio

A responsive, static dashboard concept for visual PCB inspection. Built with HTML, CSS, JavaScript, and a standalone SVG board illustration; no framework or build step is needed.

Live demo: https://trace-pcb-inspection.vercel.app/

## Run locally

Open `index.html` in a browser or serve this folder with any static web server.

## Included files

- `index.html` — page structure and metadata
- `styles.css` — dashboard styling and responsive layouts
- `app.js` — upload preview, defect overlays, zoom controls, and report export
- `assets/pcb-board.svg` — illustrated demo board
- `assets/favicon.svg` — Trace icon
- `manifest.json` — app metadata
- `vercel.json` — static hosting settings

Detection metrics and defect labels are illustrative demo data. Uploading an image previews it but does not perform real defect detection.
